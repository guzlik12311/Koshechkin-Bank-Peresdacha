## 📌 Описание проекта

Проект выполнен строго по заданию практической работы № 1 («Модульное тестирование в Visual Studio», стр. 158–170 методических указаний / руководство Microsoft Learn *«Создание и запуск модульных тестов для управляемого кода»*).

В решении реализован класс банковского счёта `BankAccount` (пространство имён `BankAccountNS`) с операциями пополнения (`Credit`) и списания (`Debit`) средств, а также разработан комплекс автоматизированных тестов с использованием фреймворка **MSTest**.

В соответствии с подходом **TDD (Test-Driven Development)**:
1. В метод `Debit` первоначально внесена намеренная ошибка (`m_balance += amount;`);
2. Тест `Debit_WithValidAmount_UpdatesBalance` выявляет ошибку (стадия **Red**);
3. Ошибка исправлена на вычитание `m_balance -= amount;`, тест успешно проходит (стадия **Green**);
4. Выполнен рефакторинг с выносом константных сообщений об ошибках (`DebitAmountLessThanZeroMessage`, `DebitAmountExceedsBalanceMessage`) и добавлением тестов граничных условий и исключений (стадия **Refactor**).

## 🧪 Набор модульных тестов (MSTest)

| Метод теста | Проверяемый сценарий | Ожидаемый результат |
|---|---|---|
| `Debit_WithValidAmount_UpdatesBalance` | Корректное списание средств ($4.55 из $11.99) | Баланс уменьшается ровно до $7.44 |
| `Debit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange` | Попытка списания отрицательной суммы (-$100.0) | `ArgumentOutOfRangeException` с сообщением `Debit amount is less than zero` |
| `Debit_WhenAmountIsMoreThanBalance_ShouldThrowArgumentOutOfRange` | Списание суммы сверх баланса ($20.0 при балансе $11.99) | `ArgumentOutOfRangeException` с сообщением `Debit amount exceeds balance` |
| `Credit_WithValidAmount_UpdatesBalance` | Корректное пополнение баланса (+$5.77 к $11.99) | Баланс увеличивается до $17.76 |
| `Credit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange` | Зачисление отрицательной суммы (-$5.0) | Выброс исключения `ArgumentOutOfRangeException` |

## 🚀 Запуск и проверка

### В Microsoft Visual Studio 2022:
1. Откройте `Bank.sln` или `Bank.slnx`;
2. В верхнем меню выберите **Тест → Запустить все тесты** (или сочетание клавиш `Ctrl+R, A`);
3. В окне *Обозреватель тестов* (Test Explorer) отображаются все успешно пройденные тесты (зелёные маркеры);
4. Для запуска демонстрационного консольного вывода назначьте проект `Bank` запускаемым и нажмите **F5** (или `Ctrl+F5`).

### Через .NET CLI:
```powershell
# Сборка решения
dotnet build Bank.sln

# Запуск тестов MSTest
dotnet test BankTests/BankTests.csproj

# Запуск приложения
dotnet run --project Bank/Bank.csproj
```
